# Where a DS component lives

One `@isbatak/panda-ds` component spans these files. `<name>` is kebab-case, `<camel>` its camelCase form.

## Recipe

- `packages/panda/ds/src/theme/recipes/<name>.ts`: the recipe or slot recipe. Its `description` says when to pick it.
- `packages/panda/ds/src/theme/recipes/index.ts`: register it in `recipes` or `slotRecipes` under `<camel>`.
- `packages/panda/ds/src/theme/recipes/shared/`: size and variant maps shared between recipes (`input.ts`,
  `segment.ts`). Reuse these so related controls line up.
- `packages/panda/ds/src/theme/conditions.ts`: custom conditions such as `_icon`, `_iconStart`, `_iconEnd`.
- Icons next to a label go in `StartIcon` or `EndIcon` (exported from each framework's `icon` module), which set
  `data-icon-start` and `data-icon-end`. A recipe that shows icons beside a label styles them with `_iconStart` and
  `_iconEnd`. Add those styles when the component's slice comes up.
- Tokens: `theme/tokens/`, `theme/semantic-tokens/`, `theme/text-styles.ts`, `theme/layer-styles.ts`.
- `packages/panda/themes/analog/src/recipes/<name>.ts`: the analog theme overrides some recipes. Change it too when the
  base recipe's API changes.

Recipes that ship on their own live in `packages/panda/<name>` instead (`code-preview`, `masonry`, `text-flip`,
`wheel-picker`, `video-player`, ...).

## Components

`packages/ui/<framework>/src/components/<name>/` with an `index.ts`, for `react`, `vue`, `svelte`, `solid`, `preact`,
`lit`. Each package exports `./<name>` from that folder. React is the reference; the others follow when a feature is
cross-framework.

## Headless machine

When Ark UI has no component for it, build one:

- `packages/zag/<name>`: the Zag state machine (`@isbatak/zag-<name>`).
- `packages/ark/<name>`: the framework bindings in `src/{react,vue,svelte,solid}` (`@isbatak/ark-<name>`).

Ark and Zag sources for upstream components are in `node_modules/.pnpm/@zag-js+<name>@<version>/` and
`node_modules/.pnpm/@ark-ui+<framework>@<version>/`.

## Demos

- `apps/compositions/src/examples/ds/<framework>/<name>/<demo>.<ext>`, for `react`, `vue`, `svelte`, `solid`. `usage` is
  the demo keyed `<name>`; any other file is keyed `<name>/<demo>`. Files starting with `_` are helpers, not demos.
- React and Solid files export `<Name><Demo>Demo` (`ButtonDemo` for `usage`, `BadgeSizesDemo` for `sizes`). Vue and
  Svelte files are the default export.
- Compositions uses `strictTokens`, so demos only use token values.
- In Vue templates, write style props in camelCase (`maxW="sm"`); Vue passes kebab-case ones (`max-w`) through as plain
  attributes.

## Stories

`apps/storybook-<framework>/src/ds/<name>.stories.<ext>`, titled `DS/<Title>`, with one story per demo (`Usage`,
`Sizes`, …). Stories import the demos from `@isbatak/compositions/ds/<framework>/<name>/<demo>` and only add states the
docs don't need. The docs page links to the `Usage` story of the picked framework.

## Docs on www

- `apps/www/content/components/ds/<name>/index.mdx`: the page. Frontmatter `links` point at the source and recipe.
  `<Usage />` shows the source of the demo keyed `<name>`; `<Example id="<name>/<demo>" />` renders the others, in the
  framework picked on the page.
- The page lives at `/ds/components/<framework>/<name>`. `/ds/components/<name>` serves the framework from the
  `docs-framework` cookie, React by default.
- `## API` with `<Api />` renders a props table per part, and `<RecipeVariants />` the recipe's variants. Both read
  `apps/www/data/ds-api.json`, generated by `pnpm api:generate` in `apps/www` from the React package's types and the
  recipe's `variantMap`. Props declared in `packages/ui` need JSDoc to get a description.
- A framework without the demo shows "Not available for <framework> yet."
- `apps/www/components/ds-demos/` only holds the React demos for pages that aren't DS components (concentric, icons,
  code-preview).

## Changeset

Add `.changeset/<slug>.md` naming every package you touched: `@isbatak/panda-ds`, `@isbatak/panda-theme-analog`,
`@isbatak/<framework>-ui`, `@isbatak/ark-<name>`, `@isbatak/zag-<name>`. The `-ui` packages are private but still get
changesets; apps don't.
