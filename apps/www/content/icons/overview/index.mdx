The icons are [Boring Icons](https://boring-icons.netlify.app), designed by
[Goran Tomičić](https://goran-tomicic.xyz).  
[ikona](https://www.npmjs.com/package/@ikona/cli) builds them into one SVG sprite, so a page loads every icon in a
single request, and `name` only accepts icons that exist.

## Use them

- [Setup](/ds/icons/setup) installs `@isbatak/icons` and renders the `Icon` component in your framework.
- [AI skills](/ds/icons/ai-skill) help your coding agent find icon names and draw new ones in the Boring style.
- [`@boring-icons/react`](https://www.npmjs.com/package/@boring-icons/react) has Boring Icons on their own, as React
  components.
