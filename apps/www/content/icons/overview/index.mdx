description: One SVG sprite of plain line icons with typed names, rendered by an Icon component in every framework.
order: 1
---

The icons are [Boring Icons](https://www.npmjs.com/package/@boring-icons/react) by [Goran](https://goran-tomicic.xyz).  
[ikona](https://www.npmjs.com/package/@ikona/cli) builds them into one SVG sprite, so a page loads every icon in a
single request, and `name` only accepts icons that exist.
