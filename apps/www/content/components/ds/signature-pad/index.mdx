Built on Ark UI's SignaturePad. Each stroke is stored as an SVG path in `paths`. The clear trigger shows once something
is drawn and defaults to an undo icon unless you give it children. The guide is the dashed line people sign on. The
stroke takes the text colour, so it follows the color mode; pass `drawing.fill` to pick another colour.

## Examples

### Controlled

Pass `paths` and `onDraw`, here to count the strokes and clear them from outside.

### Image preview

`onDrawEnd` hands you `getDataUrl`, which renders the signature as a PNG, JPEG or SVG data URL. The exported image
doesn't carry the page's styles, so the stroke is black; the preview sits on a white background.
