A `span` styled with the `ripple` recipe. Pressing it adds a circle at the pointer that grows to cover the element and
fades out, then removes itself. A keyboard click (Enter or Space) starts the ripple from the center. Use `asChild` to
put the ripple on a card, tile or button. With reduced motion the circle only fades.

## Usage

<Usage />

```tsx
<Ripple asChild>
  <Center>Click anywhere</Center>
</Ripple>
```

## Recipe

| Variable        | Description                                             |
| --------------- | ------------------------------------------------------- |
| `--ripple-x`    | Horizontal center of a ripple, set on each ripple       |
| `--ripple-y`    | Vertical center of a ripple, set on each ripple         |
| `--ripple-size` | Diameter of a ripple, large enough to cover the element |
