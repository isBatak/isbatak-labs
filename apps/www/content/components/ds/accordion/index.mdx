Built on Ark UI's Accordion. Set `multiple` to keep several items open, and `collapsible` to let the open item close.
`Accordion.ItemBody` adds the padding inside the animated content. With no children, `Accordion.ItemIndicator` shows a
chevron that turns when the item opens.

## Usage

<Usage />

```tsx
<Accordion.Root>
  <Accordion.Item value="a">
    <Accordion.ItemTrigger>
      Title
      <Accordion.ItemIndicator />
    </Accordion.ItemTrigger>
    <Accordion.ItemContent>
      <Accordion.ItemBody />
    </Accordion.ItemContent>
  </Accordion.Item>
</Accordion.Root>
```
