Built on Ark UI's JSON Tree View, which is a Tree View over a collection made from `data`. Pass any value: objects,
arrays, `Map`, `Set`, functions, errors, regular expressions, dates. `JsonTreeView.Tree` renders every node itself, so
there are only two parts. Branch arrows default to a chevron; pass `arrow` to change it.

## Usage

<Usage />

```tsx
<JsonTreeView.Root data={data}>
  <JsonTreeView.Tree />
</JsonTreeView.Root>
```
