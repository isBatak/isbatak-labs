A styled `<select>` with a chevron. Use it when you want the operating system's own picker, like the wheel on phones;
otherwise use [Select](/ds/components/select). `NativeSelect.Field` is Ark UI's `Field.Select`, so inside a `Field` it
picks up the label, helper text and the invalid, disabled and required states.

## Usage

<Usage />

```tsx
<NativeSelect.Root>
  <NativeSelect.Field>
    <option value="" />
  </NativeSelect.Field>
  <NativeSelect.Indicator />
</NativeSelect.Root>
```

`NativeSelect.Indicator` shows `chevron-down` unless you pass it other children.
