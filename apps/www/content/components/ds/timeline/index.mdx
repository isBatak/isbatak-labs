A timeline lists events in order along a vertical line. Each `Timeline.Item` holds a `Timeline.Connector` with the
separator line and indicator, and a `Timeline.Content` with the title and description.

## Usage

<Usage />

```tsx
<Timeline.Root>
  <Timeline.Item>
    <Timeline.Connector>
      <Timeline.Separator />
      <Timeline.Indicator />
    </Timeline.Connector>
    <Timeline.Content>
      <Timeline.Title />
      <Timeline.Description />
    </Timeline.Content>
  </Timeline.Item>
</Timeline.Root>
```
