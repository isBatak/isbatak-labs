Built on Ark UI's Number Input. Arrow keys step the value, Page Up and Page Down step it by ten, and the value is
clamped to `min` and `max` when the input loses focus. The input shares its sizes and variants with the `input` recipe.

## Usage

<Usage />

```tsx
<NumberInput.Root>
  <NumberInput.Control>
    <NumberInput.IncrementTrigger />
    <NumberInput.DecrementTrigger />
  </NumberInput.Control>
  <NumberInput.Input />
</NumberInput.Root>
```

The triggers render whatever icons you pass them, here `chevron-up` and `chevron-down`. For a stepper with the buttons
on either side of the value, use [Number Stepper Input](/ds/components/number-stepper-input).
