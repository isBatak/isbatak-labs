Built on Ark UI's ToggleGroup. Pressed items get `aria-pressed` and `data-pressed`. Arrow keys move focus between items.
By default one item can be pressed at a time and pressing it again clears it; `multiple` lets several stay pressed. For
a single choice that must always have a value, use [Segment group](/ds/components/segment-group).

Give icon-only items an `aria-label`, and the root a label for the whole group.
