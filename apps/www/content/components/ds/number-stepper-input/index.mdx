The same Ark UI Number Input parts as [Number Input](/ds/components/number-input), styled for quantities and counters.
The value sits in the middle with a ghost button on each side, and the label is a field-style label above the input.

## Usage

<Usage />

```tsx
<NumberStepperInput.Root>
  <NumberStepperInput.Label />
  <NumberStepperInput.Control>
    <NumberStepperInput.Input />
    <NumberStepperInput.InlineLabel />
    <NumberStepperInput.TriggerGroup>
      <NumberStepperInput.DecrementTrigger />
      <NumberStepperInput.IncrementTrigger />
    </NumberStepperInput.TriggerGroup>
  </NumberStepperInput.Control>
</NumberStepperInput.Root>
```

`TriggerGroup` lays the two triggers over the input's ends. `useNumberStepperInput` and `useNumberStepperInputContext`
are Ark's number input hooks under this component's name.
