Built on Ark UI's Splitter. List the panels in `panels`, give each `Splitter.Panel` the matching `id`, and put a
`Splitter.ResizeTrigger` between two panels with an `id` of `"<before>:<after>"`. Sizes are percentages. With no
children, `Splitter.ResizeTrigger` shows a separator line and a handle that grows while it's focused or dragged.

## Usage

<Usage />

```tsx
<Splitter.Root panels={[{ id: "a" }, { id: "b" }]} defaultSize={[50, 50]}>
  <Splitter.Panel id="a" />
  <Splitter.ResizeTrigger id="a:b" />
  <Splitter.Panel id="b" />
</Splitter.Root>
```
