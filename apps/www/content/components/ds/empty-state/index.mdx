An empty state tells people why a view is empty and, optionally, what to do next. It centres an indicator, a title and a
description, with room for actions below.

## Usage

<Usage />

```tsx
<EmptyState.Root>
  <EmptyState.Content>
    <EmptyState.Indicator />
    <EmptyState.Title />
    <EmptyState.Description />
  </EmptyState.Content>
</EmptyState.Root>
```
