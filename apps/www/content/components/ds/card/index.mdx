A card groups related content about one subject. Put a title and description in `Card.Body`, and actions in
`Card.Footer`. Set `interactive` when the whole card is clickable.

## Usage

<Usage />

```tsx
<Card.Root>
  <Card.Header />
  <Card.Body>
    <Card.Title />
    <Card.Description />
  </Card.Body>
  <Card.Footer />
</Card.Root>
```
