Built on Ark UI's Tags Input. Enter or a comma adds a tag, Backspace in an empty input selects the last tag, and
double-clicking a tag edits it. The control grows to fit the tags.

## Usage

<Usage />

```tsx
<TagsInput.Root>
  <TagsInput.Label />
  <TagsInput.Control>
    <TagsInput.Item>
      <TagsInput.ItemPreview>
        <TagsInput.ItemText />
        <TagsInput.ItemDeleteTrigger />
      </TagsInput.ItemPreview>
      <TagsInput.ItemInput />
    </TagsInput.Item>
    <TagsInput.Input />
  </TagsInput.Control>
  <TagsInput.HiddenInput />
</TagsInput.Root>
```

Render one `TagsInput.Item` per tag from `TagsInput.Context`, with its `index` and `value`.
