## Examples

### Sizes

Set `size` to `sm`, `md` or `lg`. The default is `md`.

<Example id="tooltip/sizes" />

### Placement

Pass `positioning={{ placement }}` to choose which side of the trigger the tooltip opens on.

<Example id="tooltip/placement" />

### Delay

Set `openDelay` and `closeDelay` in milliseconds to change how long the tooltip waits.

<Example id="tooltip/delay" />

### Interactive

Set `interactive` to keep the tooltip open while the pointer is over it.

<Example id="tooltip/interactive" />

### Disabled

Set `disabled` to stop the tooltip from opening.

<Example id="tooltip/disabled" />

### Controlled

Pass `open` and `onOpenChange` to follow and change whether the tooltip is open.

<Example id="tooltip/controlled" />
