Built on Ark UI's SegmentGroup. `SegmentGroup.Indicator` slides to the selected item.

## Examples

### Sizes

<Example id="segment-group/sizes" />

### Fitted

`fitted` stretches the items to fill the group.

<Example id="segment-group/fitted" />

### Tinted

`tinted` colours the indicator and the selected item with the group's `colorPalette`. Change the palette with the value
to give each segment its own colour.

<Example id="segment-group/tinted" />

### Description

Give an item a second line by stacking the `ItemText` over a muted `Span`. Set the item's height to `auto` so both lines
fit; the indicator follows the item's size.

<Example id="segment-group/description" />

### Icon only

`icon` makes the items square for icon-only segments. Give each item an `aria-label`.

<Example id="segment-group/icon" />
