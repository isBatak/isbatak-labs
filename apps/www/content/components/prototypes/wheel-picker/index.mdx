Scroll, use the keyboard or type to jump to an option. Works in React, Vue, Svelte, Solid, Preact and vanilla JS.

- Native scroll snapping, so touch momentum and trackpads feel right
- Keyboard, page keys and typeahead
- Optional looping
- Disabled items, controlled and uncontrolled values
- A hidden input for forms

## Examples

Scroll to an example to load it in the preview, and open the code view there for the full source. The settings button in
the preview changes the example live, and the snippet under it follows. Each example is its own registry item, so you
can add it with the CLI the same way.

### Controlled value

<Example id="wheel-picker-controlled" settings={{ controlled: true }}>

Pass `value` and `onValueChange` to own the state, or bind the value with `v-model` in Vue and `bind:value` in Svelte.
Anything that updates the value, like the buttons under the wheel, moves the picker to that item.

</Example>

### Looping

<Example id="wheel-picker-loop" settings={{ loop: true, defaultValue: "30" }}>

Set `loop` to repeat the items, so the wheel wraps from the last item back to the first. The items render several times
and the wheel jumps back to the middle copy whenever scrolling stops, so it never reaches an end.

</Example>

## Styling

The viewport is a scroll container with `scroll-snap-type: y mandatory`, padded so the first and last rows can reach the
middle. The highlight sits behind the rows and the Panda recipe fades the viewport edges with a mask. Where the browser
supports scroll-driven animations, each row tilts away from the middle like a drum. The row height and the number of
rows in view come from the `itemHeight` and `visibleCount` props, so size the text to fit them.

## Accessibility

The viewport is a `spinbutton` that announces the selected label through `aria-valuetext`. The rows are hidden from
assistive tech, since the viewport already reports the value. Arrow keys move one row, Page Up and Page Down move a
page, Home and End jump to the ends, and typing jumps to the next label that matches. Disabled rows are skipped, and a
flick that lands on one moves to the nearest enabled row. Give each wheel a name with `aria-label` or the label part.
