Drag, scroll, use the keyboard or type to jump to an option. Works in React, Vue, Svelte, Solid, Preact and vanilla JS.

- Mouse, touch, wheel, keyboard and typeahead
- Inertia scrolling that snaps to items
- Optional infinite looping
- Disabled items, controlled and uncontrolled values
- A hidden native select for forms
- RTL support

## Examples

Scroll to an example to load it in the preview, and open the code view there for the full source. The settings button in
the preview changes the example live, and the snippet under it follows. Each example is its own registry item, so you
can add it with the CLI the same way.

### Controlled value

<Example id="wheel-picker-controlled" settings={{ controlled: true }}>

Pass `value` and `onValueChange` to own the state, or bind the value with `v-model` in Vue and `bind:value` in Svelte.
Anything that updates the value, like the buttons under the wheel, moves the picker to that item.

</Example>

### Infinite scrolling

<Example id="wheel-picker-infinite" settings={{ infinite: true, defaultValue: "30" }}>

Set `infinite` to loop the items, so the wheel wraps from the last item back to the first. Home and End do nothing while
looping.

</Example>
