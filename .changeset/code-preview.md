Add the code preview: Ark UI style parts for React, Solid, Vue and Svelte, built on Zag.js helpers, and a Panda CSS
preset with its slot recipe. It frames a live example with a resizable stage, a source panel, and theme, direction and
copy controls. The preview wraps its children in Ark's `LocaleProvider`, so the direction toggle flips Ark components
inside it.
