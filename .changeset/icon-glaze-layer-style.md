Add the `iconGlaze` layer style: white highlights along the top and bottom edges, darker sides and a soft drop shadow
that turn a flat, single-color icon tile into a lit, rounded object. Set `--icon-glaze-intensity` to change its
strength. Add the `frostGlaze` layer style for the frosted-glass panel the icons sit on, with `--frost-glaze-intensity`.
