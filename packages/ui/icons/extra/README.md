# Extra icons

Icons that Boring Icons doesn't have, added to the same sprite. Stroke icons use a stroke width of 1.5 so they sit with
the Boring set.

| ----------------------------------------------------- | ----------------------------------------------------------------------------------- | ------- |
| `brand-anthropic`                                     | [Simple Icons](https://simpleicons.org)                                             | CC0 1.0 |
| `brand-ark`                                           | [Ark UI](https://github.com/chakra-ui/ark) logo                                     | MIT     |
| The `tabler` list in `scripts/import-extra-icons.mjs` | [Tabler Icons](https://tabler.io/icons) v3.48.0, copyright (c) 2020-2024 Paweł Kuna | MIT     |
| Everything else                                       | Drawn for this repo on the Boring Icons grid                                        | MIT     |

Brand logos are trademarks of their owners.

`pnpm --filter @isbatak/icons import:extra` downloads the Simple Icons, Ark UI and Tabler ones again. Everything else is
kept by hand; draw new ones with the [`boring-icons` skill](../../../../.claude/skills/boring-icons/SKILL.md).
